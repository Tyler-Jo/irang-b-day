# 조이랑의 첫 번째 생일

2026년 11월 14일 12:20, 롯데시티호텔 대전에서 열리는 돌잔치의 모바일 초대장입니다.

## 관리자 인증

현재 관리자 비밀번호는 소유자 요청으로 `lib/server.ts`에 고정되어 있습니다. `ADMIN_KEY` 환경 변수는 인증에 사용하지 않습니다. 아래의 `.dev.vars` 설정 설명은 이전 환경변수 방식에 관한 내용입니다.

## 기능

- 반응형 초대장, 행사 달력, 네이버 지도·카카오맵 검색, 링크 공유
- 방문자의 이름과 축하 댓글을 서버 데이터베이스에 저장
- `/admin`에서 행사 정보, 초대 문구, 상세 주소·연회장·주차 안내 수정
- 관리자 사진 일괄 업로드·삭제·대표 사진 선택·표시 순서 조정, 앨범과 확대 보기
- 관리자 댓글 삭제, 서버에서 관리자 권한 검사, 댓글 빈도 제한

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```sh
npm ci
npm run setup:local
npm run build
npm run db:migrate:local
npm run dev -- --hostname 127.0.0.1 --port 5184
```

초대장: http://127.0.0.1:5184/

관리자: http://127.0.0.1:5184/admin

`setup:local`이 `.dev.vars`에 임의의 `ADMIN_KEY`를 생성합니다. 해당 값이 관리자 비밀번호이며, 기존 파일은 덮어쓰지 않습니다. `.dev.vars`는 Git에서 제외됩니다. 비밀번호 변경 시 개발 서버를 재시작하세요.

댓글·행사 정보는 로컬 D1(SQLite), 사진은 로컬 R2에 보관됩니다. 저장 위치는 `.wrangler/state`입니다. 이 폴더를 지우면 로컬 데이터가 삭제됩니다. 운영 데이터와는 별개입니다.

현재 체크아웃에는 초기 마이그레이션이 적용되어 있습니다. `db:migrate:local`은 Wrangler의 마이그레이션 기록을 사용하며 새 환경 또는 추가 마이그레이션 적용 시 사용합니다.

## 운영 배포

`.openai/hosting.json`의 Sites 프로젝트에 `DB`(D1), `BUCKET`(R2) 바인딩을 선언했습니다. 운영 환경에는 별도의 비밀 환경 변수 `ADMIN_KEY`를 설정해야 합니다. 로컬 `.dev.vars`가 운영 환경으로 자동 복사되지 않습니다.

사이트는 처음에 비공개로 생성됩니다. 손님에게 배포하려면 운영 배포와 공개 접근 설정이 필요합니다. 로컬 주소는 현재 컴퓨터에서만 접근할 수 있습니다.

사진은 JPG, PNG, WebP 형식으로 한 장당 8MB, 총 60장까지 올릴 수 있습니다. 최신 댓글 200개를 표시합니다. 실제 사진·댓글·관리자 키·개발 도구 상태는 저장소에 포함하지 않습니다.
